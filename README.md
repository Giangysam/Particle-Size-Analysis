## Particle-Size-Analysis
Desktop application for grain size analysis using multiple sieves, with automatic calculation of the final coefficient.

##OVERVIEW

Grain Size Coefficient Calculator is a lightweight desktop application designed to simplify granulometric calculations for industrial processes.

The application allows the user to enter the weight (in grams) retained on each sieve. Each sieve diameter is associated with a predefined coefficient, automatically applied during the calculation process. The software then calculates the final granulometric coefficient by combining the contributions of all sieves according to their respective weights and coefficients.

The tool is suitable for small, medium, and large industrial plants requiring fast and reliable granulometric analysis.


##FEATURES

Simple and intuitive desktop interface
Input of retained material weight for each sieve
Automatic application of diameter-specific coefficients
Instant calculation of the final granulometric coefficient
Suitable for routine industrial quality control
No installation required
Portable executable file


##HOW IT WORKS


Enter the weight (grams or what you want) retained on each sieve.
The software automatically associates the correct coefficient with each sieve diameter.
The calculation engine processes all weights and coefficients.
The final granulometric coefficient is displayed.

The calculation considers the contribution of every sieve, ensuring an accurate overall result.
